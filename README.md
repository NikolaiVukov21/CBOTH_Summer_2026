### Scenario B:

#### Processing Old Excels:

Overview:
The goal of this project is to take the old excel files logged from Scenario B for models "B-B", "B-LR", and "B-PRC" and transformed them into the long format used in the newer excel logs. 

This project uses a rule-based heuristic parsing to map out each value with their id, group, and variable, with the assistance of spatial layout detection and Manhattan-distance nearest-neighbor matching from a semi-structured Excel Worksheets.

Additionally, this program does have some flaws, especially when dealing with un-structured and merged data.
